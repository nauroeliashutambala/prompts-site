# LubaShow AI — Biblioteca de Prompts

Site estático responsivo com biblioteca inicial de prompts, pesquisa, filtros, modal de detalhes, cópia, partilha e favoritos locais.

## Executar
- Abra `index.html` no navegador; ou
- Publique o conteúdo da pasta num alojamento estático / PHP.

Não é necessário instalar dependências nem usar uma API para a biblioteca inicial.

## Antes de publicar
1. Confirme o endereço exacto do Facebook e substitua o link de demonstração no `index.html`.
2. Confirme o username do Instagram.
3. Adicione o domínio real às canonical URLs e complete OG images quando o domínio estiver definido.
4. Se acrescentar analytics, formulários ou backend, actualize a política de privacidade.
5. Revise os prompts e adapte o português à linha editorial desejada.

## Funcionalidades incluídas
- 80 prompts com texto completo, explicação, exemplo e dicas.
- 20 categorias visuais.
- Pesquisa por título, descrição, categoria, ferramenta e texto do prompt.
- Filtros por categoria e ferramenta.
- Ordenação por título e data.
- Modal com copiar e partilhar.
- Favoritos persistidos em `localStorage`.
- Layout mobile-first e menu móvel.
- Metadados SEO básicos.
- Sem chaves de API, backend ou custos externos.

## Limitações
- "Tendências" são tratadas como selecção editorial; o site não recolhe métricas em tempo real das redes sociais.
- O botão Facebook precisa do URL directo do perfil/página.
- Não existe painel administrativo ou base de dados nesta primeira versão.
